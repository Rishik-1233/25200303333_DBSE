# Week 3 — Aggregate Functions with WHERE, GROUP BY, HAVING & ORDER BY

**Course:** Database System Engineering and Distributed Backend Development  
**Course Code:** 25CS1302E

---

Aggregate queries over a **Bank Management System** database. The exercise builds a
`bank_transactions` table and uses `COUNT`, `SUM`, `AVG`, `MIN` and `MAX` together with
`WHERE`, `GROUP BY`, `HAVING` and `ORDER BY` to answer branch- and customer-level business
questions.

> Notes by Dr. Y Subbarayudu, Department of CSE, KL University, Bachupally, Hyderabad.

## Topics Covered

- Table creation and data seeding for `bank_transactions`
- `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
- Filtering rows before aggregation with `WHERE`
- Grouping rows with `GROUP BY`
- Filtering groups after aggregation with `HAVING`
- Sorting results with `ORDER BY`
- The difference between `WHERE` and `HAVING`

## How to Run

Open **MySQL Workbench**, connect to your local instance, open a new query tab, and run the
statements in order from the notes file above. Confirm each step through the **Result Grid**
and the green tick in **Action Output**.
