STEP 1: CREATE TABLE
=========================================================

CREATE TABLE bank_transactions (
    txn_id INT PRIMARY KEY,
    customer_name VARCHAR(50),
    branch_name VARCHAR(50),
    transaction_type VARCHAR(20),
    amount DECIMAL(10,2),
    transaction_date DATE
);

QUESTION 8 - GROUP BY + HAVING
=========================================================

SCENARIO:
Management wants branches whose total transaction
amount exceeds $20,000.

QUERY:

SELECT branch_name,
       SUM(amount) AS Total_Amount
FROM bank_transactions
GROUP BY branch_name
HAVING SUM(amount) > 20000;

OUTPUT:

Branch_Name    Total_Amount
---------------------------
Vijayawada     24000.00
Vizag          27000.00

QUESTION 9 - GROUP BY + ORDER BY
=========================================================

SCENARIO:
The regional manager wants branches ranked from
highest to lowest transaction volume.

QUERY:

SELECT branch_name,
       SUM(amount) AS Total_Amount
FROM bank_transactions
GROUP BY branch_name
ORDER BY Total_Amount DESC;

OUTPUT:

Branch_Name    Total_Amount
---------------------------
Vizag          27000.00
Vijayawada     24000.00
Hyderabad      19500.00

=========================================================
QUESTION 10 - GROUP BY + HAVING + ORDER BY
=========================================================

SCENARIO:
Management wants branches that processed at least
3 transactions and wants them ranked by transaction count.

QUERY:

SELECT branch_name,
       COUNT(*) AS Total_Transactions
FROM bank_transactions
GROUP BY branch_name
HAVING COUNT(*) >= 3
ORDER BY Total_Transactions DESC;

---------------------------------
