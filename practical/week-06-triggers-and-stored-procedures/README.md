**Course:** Database System Engineering and Distributed Backend Development  
**Course Code:** 25CS1302E

Procedural SQL on a bank database: stored procedures for routine operations,
`BEFORE` / `AFTER` triggers for automatic balance validation, and an audit trail that
records every transaction.
