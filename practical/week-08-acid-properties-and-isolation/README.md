# Week 8 — Bank Database: ACID Properties and Isolation Levels

**Course:** Database System Engineering and Distributed Backend Development  
**Course Code:** 25CS1302E

---

Transaction control and concurrency on the bank database: `COMMIT`, `ROLLBACK` and
`SAVEPOINT` demonstrate the ACID properties, and the four SQL isolation levels are
compared through the anomalies each one permits.
